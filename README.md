# Site Gutmann & Silva Advogados Associados

Site estático (HTML + CSS + JS puro). Esta versão é o design publicado em
`site-gutmannesilva.vercel.app`, com as fotos reais colocadas nos espaços
`img-slot` que estavam marcados.

- Fotos em `assets/img/` (escritório e sócios otimizados; imagens das 6 áreas geradas no Figma).
- Cada espaço de imagem usa `<div class="img-slot has-img"><img …></div>`; o tamanho e a proporção continuam definidos pelo CSS de cada bloco.
- O formulário de contato ainda não envia (falta o endpoint do serviço de formulários).
- O espaço de imagem do blog ("Em breve") segue como estava, dentro do comentário.
